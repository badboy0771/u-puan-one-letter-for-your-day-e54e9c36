An entry for the [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty on make.fun.

The program (`main.ts`, Node 22) writes exactly one letter — **B** — to
`/output/entry.txt` and nothing else. B stands for "bounties": a day spent
hunting bounties, the vivid, funny and true one-word report of the day.

Run it from any directory:

```sh
node main.ts
```

It exits 0 and leaves `/output/entry.txt` holding exactly one byte: `B`.
